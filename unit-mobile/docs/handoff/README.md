# UNIT — RN 병합 핸드오프

이 폴더는 HTML 프로토타입을 기존 React Native 레포에 충돌 없이 병합하기 위한 모든 사양·계획·프롬프트를 담는다.

## 🚀 시작하기

**`START_HERE.md`를 먼저 읽으세요.** 어디에 폴더를 두고, 어떤 명령을 칠지 한 페이지에 다 있습니다.

요약:
1. 이 `handoff/` 폴더 통째로 → 본인 RN 레포의 `docs/` 안에 복사
   (RN 레포 = `package.json`에 `react-native`가 있는 폴더. 보통 `~/dev/{앱이름}/`)
2. 터미널: `cd <RN레포> && claude`
3. `START_HERE.md`의 **3번 부트스트랩 프롬프트**를 그대로 복붙
4. PR-01부터 순서대로 진행 (PR마다 `START_HERE.md` 4번 패턴 사용)
