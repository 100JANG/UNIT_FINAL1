# Debugging Prompt

```text
아래 오류를 UNIT 백엔드 문서팩 기준으로 디버깅해줘.

오류:
[붙여넣기]

먼저 할 일:
1. 관련 도메인을 판단한다.
2. Controller/Service/Repository 중 어디 문제인지 분리한다.
3. Firebase RTDB 경로 문제인지 확인한다.
4. 인증/권한 문제인지 확인한다.
5. API 계약 위반인지 확인한다.
6. 재현 테스트를 먼저 제안한다.
7. 최소 변경으로 수정안을 제시한다.

금지:
- 임시 하드코딩
- 예외 무시
- 테스트 삭제
- 구조 변경부터 하기
```
